# Switchyard local workspace

Start on **Home** with the recommended *Keep my place* setup. Choose a Model F
Labs keyboard to preview four task controls and an editable workflow; use
**Customize** when you want to change it. A source reference changes no typing,
firmware, desktop shortcut or account.

```sh
mise exec node@24.14.0 -- npm run layout:studio
```

Open the private loopback link printed at startup. That session connects local
protected storage and supported installed tools. Without the connection, the
catalog and planner still work. The standalone desktop launcher and complete
packaging remain unfinished.

The server listens on loopback and uses an exact-origin bearer boundary. Profiles
carry layouts/workflows, not credentials or local target bindings. Personal and
Work state use independent protected keys and provider/account/export/recording
policy. Configuration conversations use a specifically chosen provider; no
provider/account fallback occurs. Device and host changes have separate reviews,
baselines, readback and restoration records. These mechanisms require further
integration and physical acceptance; see the ledger before making support claims.

A Vial definition is geometry, not a configuration backup. Factory references are
not current typing evidence. Saved readouts are historical. Read the exact device
before hardware work; the existing importer accepts a saved snapshot with matrix
and layer zero, and asks for its physical choices explicitly. Preserve the F77
pilot's firmware Dvorak / US host layout. No flash/reset/bootloader or solenoid
control is offered by this suite.
