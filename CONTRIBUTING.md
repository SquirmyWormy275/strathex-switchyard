# Contributing

Thank you for helping document or improve SXSY-B122.

## Useful contributions now

- Confirmed B122, Leyden Jar, Vial, or relegendable-cap behavior.
- Corrections backed by primary sources.
- Reproducible workflow observations or test cases.
- Safety analysis for context-sensitive controls.
- Accessibility and ergonomics findings.
- Documentation and installation improvements.

## Contribution requirements

1. Explain the observed problem before proposing a permanent key or abstraction.
2. Include reproduction steps and environment details for technical changes.
3. Add tests for dispatcher, adapter, or safety-policy behavior.
4. Do not submit secrets, private prompt logs, proprietary code, or captured customer data.
5. Identify all third-party material and its license or permission basis.
6. Do not imply upstream endorsement.
7. Keep destructive controls denied by default in unknown contexts.

## Design changes

A control-map proposal should state:

- durable intent;
- observed frequency and friction;
- supported contexts;
- behavior in unknown contexts;
- visual feedback;
- safety/authority implications;
- acceptance test; and
- which candidate key it displaces.

## Licensing

The project is still finalizing file-class licenses. By submitting a contribution, you represent that you have the right to submit it. Do not submit third-party work without compatible permission and complete attribution. A formal developer certificate or contributor agreement may be adopted before the first code release.
